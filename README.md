# Dolmetsch

Перевод субтитров онлайн-встреч с немецкого на русский поверх экрана. Windows 11.

Программа сама речь не распознаёт. Она читает готовые субтитры (Teams или Windows), переводит их
и показывает перевод в окне поверх остальных. Работает в паре с [Capri](https://github.com/idemenkov93/capri):
у них общая папка с бестиарием, уроками и собеседованиями.

## Запуск

1. Распакуй архив в любую папку и запусти `Dolmetsch.exe`.
   Рядом с часами появится значок с буквой D, внизу экрана — окно перевода.
2. В звонке Teams включи субтитры: «…» → «Sprache und Sprachausgabe» → «Liveuntertitel anzeigen».

Если субтитров Teams нет (или встреча в Zoom, Meet, браузере), в правом нижнем углу появится вопрос
«Включить субтитры Windows?». «Да» запускает субтитры Windows 11; в них один раз нужно выбрать язык Deutsch.

## Окно

Снизу вверх: строка состояния, серая немецкая фраза, которая ещё дописывается, крупный текущий перевод
с именем говорящего, выше — предыдущие переводы. Под переводом — немецкий оригинал и термины из бестиария,
если они прозвучали во фразе.

- Перетаскивается мышью, размер меняется за правый нижний угол.
- При наведении мыши справа вверху появляются кнопки: пауза, мельче, крупнее, настройки, спрятать.
- Окно не забирает фокус: можно печатать в Teams.
- По умолчанию окно не видно собеседникам при демонстрации экрана.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Старт / стоп перевода | Win+Alt+J |
| Показать / спрятать окно | Win+Alt+I |
| Профиль «Урок» ↔ «Важное» | Win+Alt+Y |

Меняются в настройках. Сочетаний с Ctrl+Alt нет намеренно: на немецкой клавиатуре это AltGr
(Ctrl+Alt+Q печатает «@»). С клавишами Capri не пересекаются.

## Профили

- **Урок** — только офлайн-перевод, текст никуда не отправляется. В будни с 9 до 17 включается сам.
  Текст встречи пишется в `Уроки`.
- **Важное** — перевод через DeepL (точнее), при сбое офлайн. Нужен ключ DeepL (Настройки → Перевод).
  Бесплатного тарифа хватает примерно на 10–15 часов речи в месяц. Текст встречи пишется в `Собеседования`.

## Общая папка с Capri

```
Документы\Capri\
    Бестиарий\        словарь терминов: CSV «Deutsch;Русский;Заметка;Источник;Тема»
    Уроки\            папка на каждый урок: транскрипт.md, конспект.md
    Собеседования\    папка на каждое собеседование: транскрипт.md
```

- Положи свой CSV в `Бестиарий` — оба приложения подхватят его сами.
- Capri делает из текста урока конспект командой «сделай конспект» и предлагает новые слова в бестиарий.
- Чтобы Claude мог читать бестиарий и уроки, подключи папку `Документы\Capri` к чату в приложении Claude.

## Связка с Capri

Capri запускает Dolmetsch своей клавишей «Субтитры» (Win+Alt+U): первый раз — открывает программу и начинает
перевод, дальше — старт и стоп. Второй запуск `Dolmetsch.exe` не открывает копию, а передаёт команду первой:
`--toggle` (старт / стоп), `--start`, `--stop`, без ключа — показать окно.

## Значок в трее

Пять пунктов: показать или спрятать субтитры (он же левый клик), пауза перевода, профиль, настройки, выход.
Всё остальное — в окне настроек.

## Если что-то не работает

- Настройки → «Сохранить отчёт». В «Документах» появится `Dolmetsch-отчёт-….zip`: журнал, настройки
  и структура окон Teams. Текста встреч и имён в нём нет.
- Журнал: `%APPDATA%\Dolmetsch\dolmetsch.log`.
- Скорость перевода: `Dolmetsch.exe --bench --out bench.txt`.
- Чтение субтитров без окна: `Dolmetsch.exe --probe 30 --out probe.txt` (во время звонка).

## Как устроено

```
dolmetsch/
  capture/        источники субтитров: Teams, субтитры Windows, выбор между ними
  translate/      переводчики: офлайн (Opus-MT), DeepL, выбор по профилю
  pipeline.py     очередь: событие → перевод → окно и файл
  transcript.py   текст встречи
  glossary.py     бестиарий из общей папки, термины под переводом
  shared.py       общая папка с Capri
  ui/overlay.py   окно субтитров
  ui/prompt.py    карточка «Да / Нет»
  ui/settings.py  окно настроек
  ui/family/      общая с Capri дизайн-система: цвета, шрифты, значки, приёмы для окон Windows 11
  hotkeys.py      горячие клавиши
  app.py          связь всех частей, значок в трее, служебные режимы
```

Правила поиска панели субтитров Teams лежат в `dolmetsch/capture/teams.py` (словарь `PROFILE`).
Если Microsoft поменяет вёрстку, правится только он.

## Разработка

```
pip install -r requirements.txt pytest
python -m pytest
python -m dolmetsch
```

Сборка для Windows делается в GitHub Actions при каждой отправке в `main`; при публикации релиза
архив сам прикрепляется к нему.
